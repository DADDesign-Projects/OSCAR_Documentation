# How to Compile and Load an Effect

{: .text-blue-200 }
This tutorial explains how to compile an effect and then load it onto the OSCAR hardware platform.

## Prerequisites
You must have cloned the following repositories and configured the workspace in STM32CubeIDE:

- `DADDesign-Projects/Software_OSCAR_P01A01`
- `DADDesign-Projects/OSCAR_P01_FLasherLoader`

See: [Workspace Tutorial](./Workspace/TutoWorkspace.md)
