# 📘 Tutorials

This section offers a series of practical tutorials designed to guide developers in learning and mastering the FORGE framework. Each tutorial covers a key step — from initial setup to deployment — showing how to design, develop, and implement real-world projects..

## 🛠️ Required Tools

To follow the examples described in these tutorials, you must first install the following tools on your computer:

- **Git**
- **STMicroelectronics STM32CubeIDE**
- **STMicroelectronics STM32CubeMX**
- **STMicroelectronics STM32CubeProgrammer**
- Optional but strongly recommended for debugging: **an ST-Link probe or one of its clones**

{: .note }
> **Note**  
>These tutorials assume that you are already familiar with these tools.  
>(Many tutorials covering these topics are available online.)
