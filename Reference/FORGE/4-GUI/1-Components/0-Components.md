# GUI Components

This chapter presents the various components that form the building blocks of the framework's user interface. These elements provide a consistent, modular, and reusable foundation for creating user interfaces for audio applications and effects.

* **Core Components**
    * cUIMemory
    * cUIMenu
    * cUIParameter
    * cUIVuMeter
* **Views**
    * cInfoView
    * cParameterInfoView
    * ParameterViews
* **Managers**
    * cBypassOnOffManager
    * cMemoryManager
    * SwitchManager
* **Ready-to-Use Panels**
    * cPanelOfEffectChoice
    * cPanelOfParameters
    * cPanelOfSystemView
    * cPanelOfTone
