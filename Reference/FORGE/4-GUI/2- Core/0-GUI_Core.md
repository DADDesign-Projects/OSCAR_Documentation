# GUI Core
This module acts as the central controller for the FORGE/OSCAR user interface. It performs the following functions:

* **Orchestration** of the lifecycle of graphical components;
* **Management** of graphical resources, including fonts and color palettes;
* **Manage MIDI** events to control bybass, on  and off functions;
* **Scheduling** events for user interface components.
